# 국회 표결 시뮬레이터

제22대 국회 정당별 의석을 기준으로, 출석·찬반을 입력해 **일반 의결 · 패스트트랙 · 필리 종결 · 재의결 · 개헌 · 탄핵 · 해임건의** 정족수를 바로 시뮬레이션하는 웹 앱입니다.

## Live Demo

**[https://ember-brook-dove-sunny.grok.me](https://ember-brook-dove-sunny.grok.me)**

## 주요 기능

- 제22대 국회 정당별 의석 현황(재적·공석 반영)
- 의결 유형별 정족수 안내 (개의 1/5, 과반, 3/5, 2/3 등)
- 정당별 출석 · 찬성 · 반대 · 기권 · 불참 입력
- 시나리오 프리셋 (전원 출석, 민주당계 찬성·국힘 반대, 국민의힘 퇴장 등)
- 라이트/다크 테마, 모바일 대응 UI

## 기술 스택

- Grok App Builder (프론트엔드 SPA)
- 클라이언트 사이드 표결·정족수 계산
- 반응형 UI (Noto Sans KR)
