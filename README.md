# 국회 표결 시뮬레이터

제22대 국회 정당별 의석을 기준으로, 출석·찬반을 입력해 **일반 의결 · 패스트트랙 · 필리 종결 · 재의결 · 개헌 · 탄핵 · 해임건의** 정족수를 시뮬레이션하는 웹 앱입니다.

## Live Demo

**https://jdragon712.github.io/assembly-vote-simulator/**

## 독립 사용 (공유 화면 없음)

- 입력값은 **각 브라우저의 `localStorage`에만** 저장됩니다.
- 같은 URL을 열어도 **다른 사용자·다른 기기와 화면이 동기화되지 않습니다**.
- 서버 세션/로그인이 없어, 링크만 공유해도 각자 독립적으로 사용합니다.

## 주요 기능

- 제22대 국회 정당별 의석 현황(재적·공석 반영)
- 의결 유형별 정족수 (개의 1/5, 과반, 3/5, 2/3)
- 정당별 출석 · 찬성 · 반대 · 기권 · 불참 입력
- 시나리오 프리셋 (전원 출석, 민주당계 찬성·국힘 반대, 국민의힘 퇴장 등)
- 정당 추가/삭제, 라이트·다크 테마, 모바일 대응

## 기술 스택

- 정적 HTML / CSS / Vanilla JS
- GitHub Pages 배포
- 클라이언트 사이드 정족수 계산 + 로컬 저장

## 로컬 실행

```bash
# 아무 정적 서버나 사용
python3 -m http.server 8080
# http://localhost:8080
```
